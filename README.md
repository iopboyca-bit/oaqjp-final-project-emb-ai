# Final project

## Watson NLP Emotion Detection Application

An AI-based web application developed using Python,
IBM Watson NLP, and Flask.

## Features

- Detection of five emotions.
- Dominant emotion identification.
- Python package integration.
- Flask web interface.
- Invalid input error handling.
- Five successful unit tests.
- Pylint static analysis score of 10.00/10.

## Installation

pip install requests flask pylint

## Run the application

python3 server.py

## Run unit tests

python3 -m unittest -v test_emotion_detection

## Static code analysis

python3 -m pylint server.py
